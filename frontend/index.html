                问数支持哪些问题？
                
    支持对茶叶销售额、销量、订单趋势、茶类对比等结构化分析问题。系统基于元知识库自动召回相关表与字段，生成可执行的 SQL。复杂多表关联与口径类问题建议描述清楚时间范围与口径。
    
              
    
              
    
                数据安全与权限如何保障？
                
    平台采用 RBAC 角色访问控制，接口层强制鉴权（JWT），不同角色可访问的数据范围不同。所有问数请求均记录审计日志，便于溯源。
    
              
    
              
    
                后端依赖未就绪怎么办？
                
    在「系统状态」页可查看各依赖健康度。若显示异常，请先执行 cd docker && docker compose up -d 启动依赖服务；或点击问数页的「演示」，无需后端即可预览界面。
    
              
    
              
    
                如何导出查询结果？
                
    问数完成后，在「执行过程」面板的「查询结果」区块点击「导出 CSV」或「导出 JSON」即可下载。导出文件以 BOM 编码保存，Excel 打开中文不乱码。
    
              
    
              
    
                忘记密码怎么办？
                
    请联系平台管理员（平台管理员角色）在「权限管理 - 用户列表」中重置密码。后续版本将上线自助找回密码能力。
